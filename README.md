# Monde-sans-viande
Essai d'une carte de projection d'un monde sans viande ( JS, HTML, CSS ) 

cette carte est un essai pour travailler sur des données en temps réelles avec du HTML et voir le rendu ( git, linkedin) 

On déplace le curseur des années et on voit les terres passer du brun au vert. Chaque pays est coloré selon la part de son territoire occupée par les pâturages (une vraie donnée, issue de FAOSTAT).
Côté technique, c'est une simple page web faite avec D3.js, sans rien à installer. Les données sont chargées en direct depuis des sources ouvertes (FAOSTAT, Our World in Data), donc la carte reste à jour toute seule.
Une petite précision : les chiffres cumulés sont des ordres de grandeur, pas des résultats d'étude. Le but n'est pas de prédire, mais de donner à voir des échelles pour nourrir le débat. C'est aussi un travail de modélisation ! 


  Pour ouvrir : https://joe59260.github.io/Monde-sans-viande/carte_viande.html dans un navigateur (une connexion internet suffit, les données se chargent en ligne).
